## Review scope and blast radius

### #339 — realtime UI scaling

The PR changes 14 files across the browser WebSocket client, node state store, dashboard and node-detail views, grid virtualization helper, and contract/test fixtures.

It keeps the initial REST detail load for complete node data, then merges lightweight WebSocket summaries into the live fields. The node grid virtualizer uses a 282 px card height, matching the existing `NodeCard` minimum height. WebSocket listeners are explicitly removed on component unmount. The Rust-to-browser message fixture adds a compatibility check for the serialization boundary.

Risk is medium because this touches live presentation and client-side state, but it does not modify authentication, server authorization, or agent protocol semantics. The branch was 34 commits behind `main`; a three-way merge against then-current `main` was clean before integration.

### #340 — pinned CI action updates

The PR changes only `.github/workflows/ci.yml`, `coverage.yml`, and `release.yml`, advancing already SHA-pinned GitHub Actions dependencies. The scope is small but supply-chain-sensitive because it affects CI and releases. The reviewed action references remain commit-pinned and their version comments match the intended releases.

The original `Web Lint and Test` failure was caused by a pre-existing `nanoid@3.3.17` advisory in the shared dependency lock, not by the workflow update. `main` now forces `nanoid@3.3.18` through the workspace override and lockfile (`5fec5ba`); a frozen install and `pnpm audit --audit-level high` pass.
