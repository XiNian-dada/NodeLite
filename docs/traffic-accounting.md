# 套餐账本与节点注销

套餐用量按 UTC 自然月累计网卡计数器的增量。首次上报建立基线，用量为 0；
计费方向或月份改变时重新建立基线，Agent 重启导致计数器归零不会产生负用量。

设置页注销节点会撤销凭证、移除实时节点，并清除内存和 SQLite 中的活动套餐账本。
只有删除事务落盘后才返回成功；先前排队的用量更新不能覆盖这次删除。
清理失败会返回错误并保留凭证撤销结果，重启时会再次按有效注册表清理孤立账本。
注册表重载也会清理已注销节点。重新登记相同节点 ID 后，用量从新主机的首次上报基线开始。

历史趋势与审计日志不属于活动套餐账本。注销节点不会主动删除这两类数据，
它们继续按各自的保留策略清理；历史趋势默认保留 14 天，审计保留期由配置决定。
