系统指标采集器 (Collector)

极低开销抽取 CPU、内存/Swap、挂载盘过滤、网卡速率与丢包，首次采集自动标记 None 防尖刺。

Linux /proc & sysfs macOS sysctl / libproc

长连接与会话状态机 (Session Engine)

维护 WebSocket (WSS) 长连接，支持 Hello 握手帧、指数退避抖动重连、心跳 Ping-Pong 与 Token 热轮换。

tokio-tungstenite 自动续期与退避

Linux 套餐限速 (Traffic Control)

集成内核 Netlink `tc` 模块。当 VPS 月度流量耗尽时由 Agent 原生执行网卡整形限速，杜绝超额计费。

CAP_NET_ADMIN 隔离 月度流量周期结算
nodelite-proto 双端共享通信协议
Serde / sanitize.rs

集中定义 WireMessage 消息契约、NodeSnapshot 状态体、配置解析、严格字符清洗与边界断言。

网关、中枢引擎与存储 (Server 端)

crate: nodelite-server

安全准入与 Token 会话缓存

75% 命中率

受控槽位限制 Argon2id 并发验密（防重连风暴 OOM）；重连会话命中 LRU 缓存直接跳过硬算，握手仅需 3.92ms。

Argon2 并发槽位 ≤ 4 ConstantTimeEq 防时序反推 TOTP + Passkey (WebAuthn)

集中 Diff 广播引擎 (SharedState)

核心优化

彻底消除 $O(M \times N)$ 读锁与重复 Diff 序列化。单一后台任务（1 秒去抖）集中运算增量，通过无锁广播通道扇出给全部浏览器会话。

锁竞争 O(M) → O(1) tokio::sync::broadcast parking_lot 读写锁

双 SQLite 存储与 LRU 查询缓存

0 丢弃写入

业务指标与安全审计完全物理隔离。采用 WAL 模式、专属后台 Batch Writer 批量写入，并搭载 200 容量的 History 查询 LRU 缓存。

history.sqlite3 WAL 批量入库 / LRU 缓存 1s
audit.sqlite3 安全事件独立留存 90 天

告警评估与定时巡检引擎 (Alert Engine)
