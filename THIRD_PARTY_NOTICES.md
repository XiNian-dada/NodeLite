# Third-Party Notices

## WebAuthn support

NodeLite server binaries include the following unmodified MPL-2.0 packages at version 0.5.5 for passkey support:

- `base64urlsafedata`
- `webauthn-attestation-ca`
- `webauthn-rs`
- `webauthn-rs-core`
- `webauthn-rs-proto`

Corresponding source code for each package is available from crates.io:

- <https://crates.io/api/v1/crates/base64urlsafedata/0.5.5/download>
- <https://crates.io/api/v1/crates/webauthn-attestation-ca/0.5.5/download>
- <https://crates.io/api/v1/crates/webauthn-rs/0.5.5/download>
- <https://crates.io/api/v1/crates/webauthn-rs-core/0.5.5/download>
- <https://crates.io/api/v1/crates/webauthn-rs-proto/0.5.5/download>
