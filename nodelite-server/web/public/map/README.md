# Bundled world boundaries

`../assets/world.geojson` contains the countries dataset from
https://github.com/datasets/geo-boundaries-world-110m/blob/6cf0946a0f4d027d21686e8402f19b524c4f6385/countries.geojson
(original: 689,418 bytes; SHA-256 `4b80696f5baddcebf5780a487295f55cf7fdaa09c371534fed98a0ec5da5e7aa`).

The upstream datapackage identifies Natural Earth as the source and
ODC Public Domain Dedication and Licence (PDDL) 1.0:
https://opendatacommons.org/licenses/pddl/1-0/

It is bundled at build time so the dashboard makes no external map request.

Trailing whitespace is normalized locally; bundled SHA-256: `5a6aa8cb78090515a28743bd06863a6952bbfbe25f92aee33e0717e12a1f58bd`.
